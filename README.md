# 🚀 Indian Startup Funding EDA

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on an Indian Startup Funding dataset using **Python**, **Pandas**, and **NumPy**. The dataset contains intentionally messy real-world data, including inconsistent city names, mixed formatting, missing values, duplicate records, and funding amounts stored as strings.

The objective is to clean the dataset, transform it into a usable format, and generate meaningful business insights through data analysis.

---

## 📂 Dataset

**Dataset:** `indian_startups_fundingDADS.csv`

The dataset contains information such as:

* Startup Name
* City
* Industry
* Funding Stage
* Funding Amount (₹ Crores)
* Funding Date
* Investors
* Founded Year

---

## 🎯 Objectives

* Load and inspect a real-world dataset
* Clean inconsistent and missing data
